    로그와 문제 해결¶

    탈리 로그¶

    각 탈리는 자체 로그를 남깁니다. 대시보드의 탈리 카드 ⋮ 메뉴 → Logs에서 그 탈리의 로그 화면(/tally/<이름>/log)을 열 수 있습니다.

    빨간 테두리 ① 영역에 시간순 로그가 쌓입니다. 각 줄은 심각도로 구분됩니다.

    심각도 의미
    status / info 정상 동작·상태 변화
    warning 주의가 필요한 상황(재연결 시도 등)
    error 오류(연결 실패 등)

    연결이 불안정하거나 탈리가 예상대로 켜지지 않을 때 가장 먼저 확인할 곳입니다.

    자주 겪는 문제¶

    탈리가 목록에 안 보여요

    • 탈리와 Hub가 같은 네트워크에 있는지 확인하세요.
    • 대시보드의 Show Disconnected를 켜서 끊긴 탈리도 표시해 보세요.
    • 하드웨어 탈리라면 전원(USB)과 WiFi 설정을 점검하세요.

    탈리는 보이는데 불이 안 켜져요

    대부분 패치 누락입니다. 탈리가 믹서의 올바른 입력 채널에 패치되었는지 확인하세요 (대시보드 카드에서 채널 선택).

    믹서 연결(②)이 0이에요

    • CONFIGURATION에서 올바른 믹서를 고르고 IP/Port를 정확히 입력했는지 확인하세요.
    • OBS라면 obs-websocket 4.x 플러그인이 설치·활성화됐는지 확인하세요.
    • 믹서와 Hub가 서로 통신 가능한 네트워크에 있는지 확인하세요.

    Hub 연결(①)이 끊겼다고 나와요

    웹 화면과 Hub 서버의 연결이 끊긴 상태입니다. Hub 프로세스가 실행 중인지 확인하고 페이지를 새로고침하세요.

    플래셔가 장치를 못 찾아요

    플래싱 문서의 해결 방법(데이터용 USB 케이블, USB 드라이버)을 확인하세요.

    더 알아보기¶

    하드웨어 조립, 펌웨어 빌드, 통신 프로토콜 등 더 깊은 내용은 원본 프로젝트 문서 를 참고하세요.
