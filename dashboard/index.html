    대시보드 (TALLIES)¶

    상단 TALLIES 메뉴의 대시보드는 등록된 모든 탈리와 시스템 연결 상태를 한눈에 보여 줍니다.

    연결 상태 표시등¶

    화면 상단 오른쪽의 세 아이콘은 시스템이 정상인지 즉시 알려 줍니다.

    번호 아이콘 의미
    ① 모니터 Hub 연결. 웹 화면과 Hub 서버의 연결 수(정상이면 1).
    ② 서버 비디오 믹서 연결. 믹서에 연결됐으면 1.
    ③ WiFi 연결된 탈리 수. 현재 붙어 있는 탈리 개수.

    Hub 연결이 끊기면

    Hub 서버와 연결이 끊기면 화면 상단에 빨간 경고 배너가 뜨고, 표시 정보가 과거 값일 수 있습니다. 자동 재연결을 시도하며, 페이지 새로고침으로도 복구할 수 있습니다.

    필터 버튼¶

    탈리가 많아지면 필터로 목록을 정리합니다.

    • ① Show Disconnected — 연결이 끊긴 탈리도 함께 표시합니다. 끄면 접속 중인 탈리만 보입니다.
    • ② Show Unpatched — 아직 믹서 채널에 패치(연결)되지 않은 탈리도 표시합니다.

    버튼이 파란색이면 해당 항목을 보여 주는 상태입니다.

    탈리 카드¶

    각 탈리는 카드로 나타납니다. 카드에는 이름, 패치된 믹서 채널(예: CAM 1, 미패치면 (unpatched)), 연결 상태(CONNECTED / DISCONNECTED)가 표시되며, 우측 상단 ⋮ 메뉴로 이름 변경·패치·설정·삭제를 합니다.

    카드 색이 곧 탈리 상태입니다. 위 스크린샷은 3대가 연결된 실제 방송 상황입니다.

    카드 색 상태 의미
    빨강 Program 지금 송출 중(On-Air) — 예: Camera 3
    초록 Preview 다음 예비 — 예: Camera 2
    회색 Idle 패치됐지만 송출/예비가 아님 — 예: Camera 1

    이 색이 실제 하드웨어 탈리 라이트와 웹 탈리 화면에 그대로 반영됩니다.

    패치(Patch)란?

    탈리를 믹서의 어느 입력 채널에 연결할지 지정하는 것입니다. 채널을 패치해야 해당 카메라가 송출될 때 그 탈리가 빨갛게 켜집니다.

    웹 탈리 만들기¶

    목록 끝의 Create Web Tally 카드로 스마트폰·태블릿 브라우저를 탈리로 추가합니다. 자세한 내용은 웹 탈리를 참고하세요.
