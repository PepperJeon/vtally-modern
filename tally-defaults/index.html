    탈리 기본 설정 (Tally Defaults)¶

    CONFIGURATION 화면 아래쪽 Tally Defaults 영역에서는 모든 탈리에 공통으로 적용되는 기본 동작을 정합니다. 개별 탈리에서 따로 지정하지 않으면 이 값이 사용됩니다.

    탈리는 두 종류의 빛을 냅니다.

    • Operator Light(오퍼레이터 라이트) — 카메라 감독/조작자 쪽을 향하는 빛
    • Stage Light(스테이지 라이트) — 출연자·무대 쪽을 향하는 빛

    각각에 대해 다음을 설정합니다.

    항목 설명
    Light Brightness 밝기. 슬라이더로 조절합니다.
    Light Colors 색상 스킴. Default(전통적인 탈리 색: 빨강=송출, 초록=예비) 또는 Yellow-Pink(적록색약 사용자를 위한 대체 색).
    Display (Shows Idle / Preview State) 대기/예비 상태를 표시할지 여부. 체크하면 송출이 아닐 때도 은은하게 상태를 나타냅니다.

    Yellow-Pink 색상 스킴

    빨강·초록을 구분하기 어려운 사용자를 위해 노랑·분홍 조합을 제공합니다. 현장 스태프의 색각 특성에 맞춰 선택하세요.

    설정을 마치면 하단 SAVE로 저장합니다. 빨간 테두리 ① 영역 전체가 Tally Defaults 카드입니다.

    개별 탈리 설정

    특정 탈리만 다르게 하고 싶다면 대시보드의 탈리 카드 ⋮ 메뉴 → 설정에서 개별 값을 지정할 수 있습니다. 여기서 지정하지 않은 항목은 이 기본값을 따릅니다.
