    LIVE · ON-AIR TALLY

    카메라가 언제 송출 중인지,
    불빛 하나로.

    vTally는 ESP8266 기반의 오픈소스 WiFi 탈리 라이트입니다. 대당 약 10유로로 대부분의 방송용 믹서와 연동해, 출연자와 카메라 감독에게 On-Air를 즉시 알려 줍니다. 이 가이드는 그 중심인 Hub 소프트웨어 사용법을 다룹니다.

    시작하기 → GitHub
    📡

    WiFi 탈리 라이트

    ESP8266 기반, 배터리·USB·카메라 아웃렛 등 유연한 전원. 대당 약 10€.

    🎛️

    주요 믹서 지원

    ATEM · vMix · OBS · Roland V-8HD/V-60HD 를 하나의 Hub로 연결.

    📱

    웹 탈리

    스마트폰·태블릿 브라우저를 그대로 탈리 라이트로. 하드웨어 없이 즉시.

    🖥️

    중앙 Hub 모니터링

    모든 탈리의 연결 상태와 On-Air/Preview를 한 화면에서 관리.

    ⚡

    가볍고 빠른 프로토콜

    로컬 네트워크와 AP를 그대로 활용하는 경량 통신.

    🔓

    오픈소스 / 오픈하드웨어

    회로도부터 펌웨어·Hub까지 전부 공개.

    구성 요소¶

    vTally는 세 부분으로 이루어집니다. 비디오 믹서가 어떤 입력이 송출/예비인지 알려 주면, Hub(이 소프트웨어)가 각 탈리·웹 탈리에 색을 지시합니다.

    실제 화면¶

    vTally Hub · TALLIES

    실제 실행 중인 Hub를 그대로 캡쳐했습니다. Camera 3이 송출 중, Camera 2가 예비입니다.
