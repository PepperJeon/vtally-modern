    비디오 믹서 연결 (CONFIGURATION)¶

    Hub가 탈리를 켜려면 먼저 어떤 입력이 송출(Program)/예비(Preview)인지 알아야 합니다. 그 정보를 주는 것이 비디오 믹서입니다. 상단 CONFIGURATION 메뉴에서 사용할 믹서를 고르고 접속 정보를 입력합니다.

    믹서 선택¶

    Video Mixer 영역의 드롭다운 ① 에서 사용할 믹서를 선택합니다. 선택하면 그 믹서에 맞는 설정 항목이 아래에 나타납니다.

    지원 믹서: ATEM · vMix · OBS Studio · Roland V-8HD · Roland V-60HD, 그리고 테스트용 Test / Mock, 사용 안 함(Off).

    설정을 바꾼 뒤에는 SAVE

    각 믹서 설정 카드 우측 아래 SAVE 버튼을 눌러야 반영됩니다. 값이 유효하지 않으면 저장이 비활성화됩니다.

    ATEM (Blackmagic Design)¶

    네트워크로 ATEM 스위처에 연결합니다.

    • ATEM IP — ATEM 장치의 IP 주소
    • ATEM Port — 접속 포트(기본값 사용을 권장)

    vMix¶

    같은 네트워크의 vMix에 연결합니다.

    • vMix IP — vMix가 실행 중인 PC의 IP
    • vMix Port — vMix TCP API 포트

    OBS Studio¶

    OBS Studio에 네트워크로 연결합니다.

    • Obs IP / Obs Port — OBS가 실행 중인 PC의 주소와 포트(기본 4444)
    • On-Air Status — 무엇을 "송출 중"으로 볼지 결정하는 모드

    obs-websocket 4.x 필요

    OBS 연동에는 obs-websocket 플러그인 4.x 버전이 설치되어 있어야 합니다. 플러그인 5.x는 (원본 기준) 아직 지원되지 않습니다.

    Roland V-8HD¶

    Roland V-8HD는 USB(MIDI) 로 연결됩니다. 따라서 IP가 아니라 요청 주기를 설정합니다.

    • Request Interval — 믹서 상태를 얼마나 자주 조회할지(밀리초). 값이 작을수록 반응이 빠르지만 부하가 커집니다.

    USB 연결

    V-8HD는 Hub가 설치된 컴퓨터에 USB로 직접 연결해야 합니다.

    Roland V-60HD¶

    Roland V-60HD는 네트워크(LAN) 로 연결됩니다.

    • IP / Port — V-60HD의 주소와 포트
    • Request Interval — 상태 조회 주기(밀리초)

    Test / Mock 믹서 (하드웨어 없이 테스트)¶

    실제 믹서 없이 Hub 화면과 탈리 동작을 확인할 때 사용합니다. 자동 테스트용이므로 평상시에는 직접 고를 필요가 없습니다. 개발 모드에서 백엔드를 --with-test로 실행하면 자동으로 켜집니다.
