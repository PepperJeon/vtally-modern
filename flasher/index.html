    하드웨어 탈리 플래싱 (FLASH)¶

    상단 FLASH 메뉴의 Tally Flasher는 ESP8266 기반 하드웨어 탈리에 펌웨어(소프트웨어)와 설정을 굽는 도구입니다. 이 가이드는 Hub 소프트웨어 사용에 초점을 두므로, 이 화면은 개요만 다룹니다.

    웹 탈리만 쓸 거라면 건너뛰어도 됩니다

    스마트폰·태블릿을 웹 탈리로 쓰는 경우 하드웨어 플래싱은 필요 없습니다.

    화면 살펴보기¶

    빨간 테두리 ① 영역이 Tally Flasher 화면 전체입니다. 이 도구는 Hub가 실행 중인 컴퓨터에 USB로 연결된 ESP8266 장치를 찾습니다.

    스크린샷은 장치가 연결되지 않은 상태입니다. 노란 안내(Did not find any connected device.)와 함께 Possible fixes(해결 방법) 가 표시됩니다.

    • 탈리를 Hub 컴퓨터에 USB로 연결하세요.
    • 일부 USB 케이블은 충전 전용입니다. 반드시 데이터 전송용 케이블을 사용하세요.
    • 이 컴퓨터에서 한 번도 인식된 적이 없다면 USB 드라이버가 없을 수 있습니다.
    • 연결 후 우측 상단 새로고침(⟳) 또는 TRY AGAIN을 눌러 다시 검색합니다.

    장치를 연결하면¶

    ESP8266이 인식되면 다음 작업이 가능합니다.

    • Software Update — 최신 vTally 펌웨어로 업데이트(Update now)
    • Edit tally-settings.ini — 장치에 저장된 WiFi/서버 등 설정 파일 편집

    굽는 동안에는 진행 상황 창이 뜨며, 완료될 때까지 창을 닫지 마세요.

    펌웨어 준비

    플래싱하려면 빌드된 펌웨어 파일이 있어야 합니다. 자세한 하드웨어 조립·펌웨어 빌드는 원본 프로젝트 문서를 참고하세요.
