    Getting Started¶

    This document covers running the Hub and connecting to the web screen for the first time.

    What you need¶

    • A computer with vTally Hub installed (Windows, macOS, or Linux)
    • A WiFi router on the same network as your tallies
    • (Optional) A video mixer to connect. Even without hardware, you can preview the screens with the built-in Test/Mock mixer.

    Node.js version

    The Hub runs on Node.js. The original project was built targeting Node.js 14, and development mode runs as two processes: the frontend (port 3001) and the backend (port 3000).

    Running the Hub¶

    If you use the distributed package, it starts from a single executable. To run it in development mode from source, do the following.

    # 1) Install dependencies
npm install --also=dev

# 2) Frontend (separate terminal)
npm run start:frontend

# 3) Backend (yet another terminal)
npm run start:backend

    Once running, the backend serves the web screen at http://localhost:3000 (proxied to the frontend). Open this address in your browser.

    Try it without hardware

    If you run the backend with the --with-test option, the built-in Test mixer is enabled, so you can look around the screens as if things were connected, even without a real mixer or tally.

    First screen — the dashboard¶

    When you connect, the TALLIES screen (the dashboard) opens.

    The Create Web Tally button in red outline ① lets you instantly turn a smartphone or tablet into a tally (→ Web Tally).

    The three menus in the top navigation are the main branches of this guide.

    Menu Screen Description
    TALLIES Dashboard Monitor the tally list and connection status
    CONFIGURATION Mixer connection · Tally Defaults Select the mixer and set tally default behavior
    FLASH Flashing Burn firmware to ESP8266 hardware
