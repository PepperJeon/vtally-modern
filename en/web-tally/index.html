    Web Tally¶

    A web tally uses the browser screen of a smartphone, tablet, or laptop directly as a tally light. You can use it right away without building a hardware tally, which makes it handy for backup cameras or temporary setups.

    Creating a web tally¶

    On the Dashboard, press the Create Web Tally card at the end of the list to open the name entry dialog.

    1. ① Name — Enter the tally name (e.g. studio-cam). A name that identifies the camera works best.
    2. ② Create — Press it to create the web tally, which then appears in the dashboard list.

    Duplicate name

    If you enter a name that already exists, a warning appears and Create is disabled. Use a different name.

    Opening the tally screen¶

    Open the tally you created in the browser of the device you'll use at that camera. The screen fills entirely with a single color so the state is visible from a distance.

    • The center shows the tally name and the current status (Idle / Preview / Program, etc.).
    • Tuner icon at the top right — the individual settings for this tally, such as brightness and color
    • Fullscreen icon at the bottom right — switch to fullscreen (recommended on site)
    Status Color Meaning
    Program Red Currently on-air (On-Air)
    Preview Green Next in preview
    Idle Dark/black Standby

    Keep the screen from turning off

    The web tally prevents sleep so the screen won't turn off automatically. Leave it in fullscreen while in use.

    Patching¶

    Just like a hardware tally, a web tally must be patched to a mixer channel to light up red when the corresponding camera goes on-air. Patch it by selecting a channel on the dashboard card (see Dashboard).
