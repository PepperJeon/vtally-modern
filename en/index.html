    LIVE · ON-AIR TALLY

    Know exactly when a camera is on air.

    vTally is an open-source WiFi tally light built on the ESP8266. At about €10 per unit, it works with most broadcast mixers and instantly tells talent and camera operators who is live. This guide covers the heart of the system — the Hub software.

    Get Started → GitHub
    📡

    WiFi tally light

    ESP8266-based, flexible USB power (battery, camera outlet, mains). ~€10 per unit.

    🎛️

    Major mixers supported

    ATEM · vMix · OBS · Roland V-8HD/V-60HD — all through a single Hub.

    📱

    Web tally

    Turn any phone or tablet browser into a tally light — instantly, no hardware.

    🖥️

    Central Hub monitoring

    Manage every tally's connection and On-Air/Preview state from one screen.

    ⚡

    Fast, lightweight protocol

    Uses your local network and access points with lean communication.

    🔓

    Open source / open hardware

    Everything is public — from schematics to firmware to the Hub.

    Components¶

    vTally has three parts. The video mixer reports which input is program/preview, and the Hub (this software) tells each tally and web tally what color to show.
