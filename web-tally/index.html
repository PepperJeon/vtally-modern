    웹 탈리 (Web Tally)¶

    웹 탈리는 스마트폰·태블릿·노트북의 브라우저 화면을 그대로 탈리 라이트로 사용하는 기능입니다. 하드웨어 탈리를 만들지 않고도 바로 쓸 수 있어, 예비 카메라나 임시 현장에 유용합니다.

    웹 탈리 만들기¶

    대시보드의 목록 끝 Create Web Tally 카드를 누르면 이름 입력 창이 열립니다.

    1. ① Name — 탈리 이름을 입력합니다(예: studio-cam). 카메라를 구분할 수 있는 이름이 좋습니다.
    2. ② Create — 누르면 웹 탈리가 생성되어 대시보드 목록에 나타납니다.

    이름 중복

    이미 있는 이름을 입력하면 경고가 뜨고 Create가 비활성화됩니다. 다른 이름을 사용하세요.

    탈리 화면 열기¶

    생성한 탈리를 그 카메라에서 쓸 기기의 브라우저로 엽니다. 화면은 전체를 한 가지 색으로 채워 멀리서도 상태를 알 수 있습니다.

    • 가운데에 탈리 이름과 현재 상태(Idle / Preview / Program 등) 가 표시됩니다.
    • 우측 상단 튜너 아이콘 — 이 탈리의 밝기·색상 등 개별 설정
    • 우측 하단 전체화면 아이콘 — 전체화면으로 전환(현장에서 권장)
    상태 색 의미
    Program 빨강 현재 송출 중 (On-Air)
    Preview 초록 다음 예비
    Idle 어두움/검정 대기

    화면 꺼짐 방지

    웹 탈리는 화면이 자동으로 꺼지지 않도록 절전(sleep)을 막습니다. 전체화면으로 두고 사용하세요.

    패치하기¶

    웹 탈리도 하드웨어 탈리와 똑같이 믹서 채널에 패치해야 해당 카메라 송출 시 빨갛게 켜집니다. 대시보드 카드에서 채널을 선택해 패치하세요(대시보드 참고).
